## 是什么

OFFICE ZOO,中文叫"班味剧场"。把"狼人杀"的设定换成职场:
- 村民 = 打工人猫 / 狼 = 资本家狗 / 中立 = 摸鱼党
- 9 个 NPC 全是 LLM 驱动,自主开会、互相阴阳、投票"优化"
- 玩家不下场,只看戏

## 三种玩法

1. 鼠人公司 — 2.5D 写字楼 GameMap,9 个 AI 自由活动 + 自演职场众生相(刚做完客户端 RAF + Catmull-Rom 走廊动画)
2. 全程开麦 — 沉浸模式,Minimax speech-2.8-hd 真人 TTS 把发言读出来
3. 裁了么 — 1v1 跟 AI HR 见招拆招,5 关进度,每关绑《劳动合同法》某一条

## 技术栈

- 前端:Vite 6 + React 18 + Zustand + Framer Motion + Tailwind 4
- 后端:Hono + Socket.IO + tsx --watch
- AI:
  - LLM: QingYun(gpt-4o-mini)→ MiniMax-M2 fallback → canned 兜底
  - TTS: Minimax t2a_v2 speech-2.8-hd → t2a_pro → QingYun → Web Speech 兜底
  - 图片: flux-schnell → doubao-seedream → qwen-image → gpt-image-1 → minimax:image-01

最骚的细节:Activity 模型 + 6 tick × 1.5s 自由活动 + 客户端 60 fps lerp

[Title]
Show HN: Office Zoo – 9 LLM agents play workplace werewolf in your browser

[Body]
I built a small open-source project where you watch 9 LLM-driven NPCs
play a werewolf-variant set in a Chinese big-tech office. The "wolves"
are HR/management trying to lay off the "villager" engineers. You don't
play — you just watch them argue, gaslight, and vote each other out
using authentic corporate jargon ("alignment", "ownership", "first-principle
thinking", "leverage", etc).

Three modes:
- Classic: 2.5D isometric office, players free-roam between rooms
  (kitchen / meeting room / server room / boss office), animated via
  RAF + Catmull-Rom corridor splines
- Immersive: round-table mode with real-voice TTS (Minimax speech-2.8-hd,
  23 distinct voices mapped to roles)
- "FightHR": 1v1 negotiation against an AI HR with 5 progressive boss
  levels, each tied to a specific clause of Chinese Labor Contract Law

Stack: React 18 + Vite 6 + Hono + Socket.IO. Three-tier LLM fallback
chain (QingYun → MiniMax-M2 → canned). Three-tier TTS fallback chain
(Minimax → QingYun → Web Speech API).

Most fun part was prompt engineering — the system prompt forces each
agent to use 3+ corporate buzzwords and call colleagues "同学"
(comrade-classmate, the standard term inside Alibaba). The AI dialogue
is occasionally sharper than what I've actually heard at work.

MIT licensed. Repo: https://github.com/ChrisChen667788/office-zoo
