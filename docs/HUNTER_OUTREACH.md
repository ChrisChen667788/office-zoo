## 0. 为什么要找 hunter?

| 维度 | 无 hunter | 有活跃 hunter |
|---|---|---|
| Launch 当日曝光 | 仅靠 maker 个人圈 | hunter 全 follower 看到推送 |
| PH 评论冷启 | 自己刷面子 | hunter 先评论提问, 真用户跟进 |
| 算法权重 | 普通 | hunter 历史 launch 成绩 boost |
| 24h upvote | 经验 50-150 | 经验 200-500+ |

**典型 ROI:** 找对一个 hunter,launch 当日 upvote +30-50%,GitHub stars
+100-200,值得投入 3-5 天去 outreach。

## 1. 目标 hunter 画像

我们项目的"完美 hunter"应该至少满足 2 个:

- [ ] **focus 包含**: AI agents / open-source / Asian tech / developer tools
- [ ] **PH 主页**: 过去 12 个月至少 hunt 过 5+ 产品,upvote 数稳定 100+
- [ ] **Twitter ≥ 5k followers**(用于发布日 amplify)
- [ ] **公开愿意 hunt 别人产品**(bio 里写"DM me to hunt your product" / "hunts startups")
- [ ] **不在 PH 工作**(internal 员工有利益冲突)

## 3. 外联 timeline

```
T-14d  挑出 Tier 1 的 3 个人, 加 Twitter 互动一周(转他们的 hunt,
       留评论, 不发任何 ask)— 让他们知道你存在

T-7d   挑出最热乎的 1 个发外联 DM(模板见 §4)。
       如果 24h 无回, 顺位下一个 Tier 1。

T-5d   确认到 hunter → 发资料包 (zip 见 §5)

T-3d   如果还没找到, 退而求 Tier 2 + 自己 hunt
       (PH 允许 self-hunt, 只是 boost 小)

T-1d   最终确认 launch 日 + 时区 (PST 00:01 = 北京 16:01)
       同步给 hunter, 发布前 2 小时再确认一次
```

## 6. 给 hunter 你能 offer 什么(让对方 yes 的杠杆)

按效果倒序:

1. **公开 credit**: 在 README "Hunted by [@handle]" + 技术博客致谢 + 发布
   后的所有 cross-post 都带 hunter handle
2. **早期访问**: 发布前 7 天给 hunter 一个 demo URL + 私下提问 channel
3. **流量回报**: launch 之后帮他们的项目转推 / 留好评 / 在 newsletter 提及
4. **金钱**: PH 文化上避免直接付费 hunt(会被打 "paid promotion" 标签影响
   排名), 但**赞助 hunter 个人项目 / newsletter 是 OK 的**, 50-200 USD
   是常见区间
5. **未来 hunt 互助**: "下次你 launch 新东西, 我帮你 cross-post 到中文圈"

## 7. 如果 24h 没找到 hunter — backup plan

PH 允许 **self-hunt**(自己是 maker 也能 hunt 自己),只是少了 hunter 的
follower boost。如果到 T-1d 还没确定 hunter:

1. 自己 hunt → 锁定 launch 时间不动摇
2. 把"找 hunter"预算移到"找 20 个朋友提前 upvote"
3. Twitter / 即刻提前 24h 发**有时间戳的预告**("明天 16:01 上线
   ProductHunt, 求 upvote"), 让粉丝设闹钟

self-hunt 的成功 case 比想象中多 — 关键还是产品本身 + first-comment 质量
+ cross-post 节奏。Hunter 是 amplifier 不是 lifesaver。

## 9. 联系迹象 — 看到这些信号说明 hunter 接的概率高

- ✅ 24h 内回了"interesting, let me look"
- ✅ 跑去你 PH profile 看了一眼(部分 hunter 会公开)
- ✅ Twitter 转了一下你的 building-in-public tweet
- ✅ 主动问"when are you launching"

如果只是 emoji 回复 / 客气感谢但没下文 → 准备顺位下一个。

## 10. 第一次外联失败的常见原因

| 症状 | 修正 |
|---|---|
| 没回信 | 标题太长 / 太"求"的语气 — 改成"show you something" 不要"hunt my product" |
| "我现在很忙" | 没提供具体日期 → 让对方好排程, 明确说 "any day in next 2 weeks works" |
| "this is cool but not for me" | 受众不对 → 换 tier 2 / 3, 别浪费时间 |
| 完全沉默 | 可能 inbox 被淹 → 一周后 follow-up 一次, 之后放弃 |
