## 2. 核心 token 一览

实现在 `packages/client/src/constants/design.ts` 末尾 `mihoyo` 命名空间。
**additive** — 不动现有 `colors`, 现有 60+ 页面无 regression。

### 2.1 元素六色系

| 元素 | core | 用法 | 对应 archetype |
|---|---|---|---|
| frost ❄️ | `#7fd4ff` | 浅冷蓝, 主调 | introvert 社恐 |
| inferno 🔥 | `#ff5566` | 火红 | hot_tempered 暴躁 / 卷王 |
| stigma 💜 | `#c084fc` | 雷紫 | passive_aggressive 阴阳人 |
| aurora 🌿 | `#a3e635` | 黄绿 | sycophant 舔狗 |
| solar 🌟 | `#ffd58a` | 金黄, 5★ 触发色 | workaholic 5★ 触发态 |
| void 💗 | `#ff5588` | 主舞台粉红 | 主 CTA / sass_master |

每元素 3 色 `{ core, halo, glow }`:
- **core**: 文字 / 边框 / 实色
- **halo**: 卡牌底色, alpha 0.18
- **glow**: 阴影 / 外发光, alpha 0.42-0.50

### 2.2 5★ / 4★ / 3★ rarity

```ts
mihoyo.rarity.r3 = '#a8a8c0'  // 基础 archetype
mihoyo.rarity.r4 = '#a78bfa'  // 演化过一次
mihoyo.rarity.r5 = '#ffb84c'  // 罕见演化 / 评级 SSR
```

每张 archetype 卡显示星级,演化后升星 → "你抽到了 5★ 卷王" 触发庆典动画。

### 2.3 Gradient mesh 背景

替代旧的 `radial-gradient(circle at 30% 20%, #1a0d35 0%, ...)`:

| token | 用途 |
|---|---|
| `mihoyo.mesh.heroDawn` | Landing / 主页 |
| `mihoyo.mesh.barNight` | 🍺 深夜酒馆 (amber → wine) |
| `mihoyo.mesh.tarotMystic` | 班味占卜升级版 (purple → cobalt) |

每个都是 3 层 radial 叠 1 层 linear,模拟米哈游主页的"环境光晕"。

### 2.4 Hexagonal stigma 切角

```ts
mihoyo.shape.hexCard
// → 'polygon(8% 0, 92% 0, 100% 12%, 100% 88%, 92% 100%, 8% 100%, 0 88%, 0 12%)'
```

应用 `clipPath: mihoyo.shape.hexCard` → 卡片变成 8 顶点 chamfered,告别
普通圆角矩形。Honkai stigma 同款。

### 2.5 STIGMA chip helper

```tsx
<div style={stigmaChipStyle('stigma')}>STIGMA · TYPE 4★</div>
```

一行生成"米哈游 ALL CAPS tracking 风"的标签:
- 字号 11px / weight 800 / letter-spacing 0.28em / TEXT TRANSFORM
- 元素 halo bg + core border (alpha 0.55)
- 圆 999 pill radius

## 4. Style guide do / don't

### ✅ Do

- **元素 halo + core 一起用** — bg 用 halo, border 用 core. 单独用 core 太刺眼.
- **5★ 时机省着用** — 只在 archetype 演化 / 抽到稀有卡时触发 `glow.fivestar`. 用多了就不稀罕了.
- **STIGMA caption 优先于普通 label** — 任何 "TYPE / TIER / KIND" 标签都升级.
- **Mesh bg 配 noise / film grain** — 米哈游 UI 常配 0.04-0.08 alpha 颗粒纹理, 让纯渐变不"塑料".
- **Hex card 限 hero / archetype 卡** — 普通卡列表别全切, 视觉密度会爆.

### ❌ Don't

- **不要把 6 元素一次性堆在一个页面** — 一个 surface 主用 1-2 个 element, 其余降到 0.06 alpha 作 accent.
- **不要给所有按钮加 glow** — 主 CTA 才发光, 否则失去层级.
- **不要乱混 rarity 星级** — 一个用户 profile 卡只显示 1 个 rarity, 不要叠.
- **不要在小屏挤六边形** — clipPath hexCard 在 < 280px 宽度上锐角会糊, 退回 radius.lg.
- **不要丢弃 v6.0 的内容** — 老 `colors` 命名空间保留, 现有 60+ 页面继续工作.

## 7. 测量

如何判断"米哈游化"是否成功?

- ✅ 用户截图发朋友圈, 评论区出现"哪个游戏" / "这是手游?" 的误判 = 视觉过线
- ✅ Z-gen 测试用户主动谈论"我抽到的卡是什么星" = 系统进入认知
- ✅ Profile / Settings 页停留时长 +50% = 米哈游级 UI 让人想停留
- ❌ 老用户(v6.0 前)反馈"花里胡哨" = 强度过头, 回调 element 饱和度
