# v0.5.1 · 劲爆动画特效包

> 用户原话:**"目前每个模式都少了点劲爆的动画特效,可以在下一版本增加"**
>
> 三个模式的关键节点都需要"剧场感",不只是"事件发生"。本文档把全部动画拆成 8 个独立 hook,任何一个都可以单独 ship,不用打包一起做。

---

## 现状(v0.5.0)

- ✅ 当前发言者头像 1.18× + 房间脉冲光晕
- ✅ 足迹粒子(team 色)
- ✅ 房间间 Catmull-Rom 走弧
- ✅ EliminationReveal 全屏 3s overlay(已存在)
- ❌ Kill 没有"被人优化的瞬间"剧场感(只有事后 reveal)
- ❌ 投票开除没有 "你被淘汰了" 离场动画
- ❌ 紧急全员会切换无视觉锚点
- ❌ 阵营胜利没有 confetti / 烟花
- ❌ 长发言/暴论没有视觉强调(目前只是文字静态弹出)
- ❌ TTS 真人音色播放时没有声波频谱可视化

## 8 个独立动画(按 ROI × 视觉冲击排序)

### A. Kill 闪击(Classic + Immersive)
**触发:** `'game:kill'` socket event
**视觉:**
- 全屏 0.15s 红光闪烁(`box-shadow: inset 0 0 200px #ff3355`)
- 受害者头像剧烈颤抖 0.4s,然后 Y 轴翻转 90° + 渐隐
- 凶手头像不动,边缘红色发光 1s
- 房间地板溅一抹红色尘土(用现有 footprint 系统,team='dog' 改色为 #ff0033)
**文件:** `components/game/KillFlashOverlay.tsx`(新),`GameMap.tsx` 调度
**工时:** 4-6h

### B. 投票淘汰离场(Classic + Immersive)
**触发:** `'game:vote_result'` with eliminated
**视觉:**
- 被淘汰玩家头像周围浮现 8 个红色 X(像 emoji vote)绕圈 1s
- 头像被"上拉吊起"出场(translateY -200, opacity 0)1.2s + 慢动作
- 同步播放 sfx.playGavel()(法槌音,已有)
- 屏幕下方滑入"💼 {name} 已被全员投票开除"横条 banner 2s
**文件:** `components/game/VoteEjectAnimation.tsx`(新)
**工时:** 4-5h

### C. 紧急全员会切换(全模式)
**触发:** `'game:phase_change'` to 'meeting'
**视觉:**
- 全屏 0.4s 红色警报扫光(从上到下 linear-gradient 动画)
- 警报音 sfx.playAlert()(新增,1s mp3 自带)
- 标题"🚨 紧急全员会"以打字机效果浮现 0.6s,然后渐隐
- 屏幕轻微 shake(2px × 4 次)
**文件:** `components/onboarding/EmergencyMeetingTransition.tsx`(新)
**工时:** 3-4h

### D. 暴论震屏(Immersive 主)
**触发:** speech 包含 ≥3 个阿里黑话词 OR 长度 > 80 chars
**视觉:**
- 文字气泡背景由"半透明黑"切换到"红黑渐变"
- 字符以 0.05s 间隔逐个浮现(打字机效果)+ 每个字微 shake
- 当前发言者头像 scale 1.2 → 1.0 弹性
- 屏幕 0.2s 微震 1px
**文件:** `components/game/SpeechBubble.tsx` 增强
**工时:** 5-6h

### E. 阵营胜利庆祝(全模式)
**触发:** `'game:over'` with winner != 'none'
**视觉:**
- 全屏 confetti(用 Lottie `lottie.confetti`,已有)
- 胜利阵营头像滑到中央 → 围成圆形 → 3s 后散开
- 巨型阵营 logo 浮现(打工人/资本家/摸鱼党 team icon × 6)+ 慢慢旋转
- 失败阵营黑白滤镜 + 翻倒动画
**文件:** `components/game/WinnerCelebration.tsx`(新),HighlightReel 触发前播 3s
**工时:** 6-8h

### F. 角色发言声波频谱(Immersive)
**触发:** TTS 音频开始播放
**视觉:**
- 当前发言者头像底部出现 5 条柱状声波,根据 audio analyser 实时跳动
- 用 Web Audio API 的 `AnalyserNode` 接 audioUnlock 的 shared element
- 柱子颜色 = 阵营色
**文件:** `utils/audioUnlock.ts` 加 analyser hook,GameMap 渲染柱子
**工时:** 6-8h

### G. 房间切换转场(Immersive)
**触发:** `phase_change` 到 discussion / voting
**视觉:**
- 当前圆桌 zoom out 0.3s
- 黑色幕布从两侧拉合 0.2s
- 中央打出 "讨论开始" / "投票时间" 招牌文字
- 黑色幕布拉开 0.2s
**文件:** `components/game/PhaseTransition.tsx`(新)
**工时:** 4h

### H. 走廊"赶路急刹"(全模式 dead-reckoning 增强)
**触发:** 玩家 destination 切换 OR commute 抵达
**视觉:**
- 起步:足迹粒子 burst(一次性散 5 个)
- 急停:头像前倾 0.15s 然后回正
- 抵达:房间地板涟漪 1 圈(circle expand + fade)
**文件:** `GameMap.tsx` 增强(已有 footprint pool 复用)
**工时:** 3-4h

## 性能预算

- 单帧 < 16ms(60fps)— 所有动画走 framer-motion + canvas,不上 React re-render
- 同一时刻最多 2 个全屏 overlay(不要叠 4 层)
- 移动端 throttle:`prefers-reduced-motion: reduce` 媒体查询关掉所有 shake / confetti

---

## 可观测性

每个动画首次触发上报一次:
- `console.debug('[anim] kill flash for player_3')`
- 用户上报"卡顿"时方便定位是哪一帧

- 阵营胜利:截图能直接当 viral 短视频封面
- 暴论震屏:能让人下意识"哦?"
