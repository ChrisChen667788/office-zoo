## 1. 全网竞品扫描(2026 年 4 月实时)

### 中文阵地

| 产品 | 形态 | 痛点 / 缺口 |
|---|---|---|
| **桥桥子(小红书 AI 脱口秀演员)** | 单一 AI 主播,文案 + 数字人剪辑视频 | 24h 涨粉 30k → 2 个月 200k+。证明"AI 讲段子"市场存在。但形象单一,用户不能定制 |
| **AIGCPanel** | 开源数字人创建平台 | 通用建站工具,没有内容垂直 |
| **科大讯飞虚拟人** | 企业级数字人 SaaS | 偏 B 端宣讲,无段子味 |
| **罗永浩 + 喜剧之王单口季 AI 段子** | 真人脱口秀演员开始用 AI 写开场白 | 没产品化,只是工具流 |
| **剪映 AI 数字人** | UGC 视频工具,主打口播 | 缺脱口秀场景模板 |
| **秋果计划数字人 SaaS** | 几百元起的低价数字人 | toC 玩家自创内容 |

### 海外阵地

| 产品 | 形态 | 痛点 / 缺口 |
|---|---|---|
| **AI Standup (tikareview.com)** | "Comedian Character Engine" — 选种族/年龄/装扮捏一个,生成全套 standup 视频 | **直接竞品!** 但纯英文,文化输出不到中文打工人圈 |
| **FunnyGPT (Medium/The Generator)** | LLM 生段子,15s 出"tight five" | 纯文本,没有数字人 |
| **Stand-up Comedy Generator (yeschat.ai)** | GPT 包装的段子生成器 | wrapper 工具,没有内容沉淀 |
| **Creatify** | AI 数字人广告工具(75 种语言唇动) | 偏广告,无脱口秀垂直 |
| **D-ID 头像生成** | 2D 静态照片活化 | 工具属性 |

### 启示

1. **垂直空缺巨大** — 没有人做"职场脱口秀 + 数字人 + 中文打工人议题"组合
2. **桥桥子证明市场** — 单 AI 主播能 200k 粉,我们做"用户 1 人定制 1 个 AI 段子手"是 N 倍机会
3. **海外 AI Standup 是模板** — Comedian Character Engine 玩法可以借鉴,加上中文文化锚 + 职场垂直
4. **不要做 SaaS 工具** — 做"内容平台+UGC", 不是"建站平台"

## 2. 我们做的差异化

| 维度 | 桥桥子 | AI Standup | OFFICE ZOO 脱口秀 |
|---|---|---|---|
| 数字人定制 | 单一主播 | ✅ 自由捏 | ✅ 自由捏 + 职场角色模板(实习生 / 中层 / CEO / HR) |
| 段子题材 | 杂泛 | 杂泛 | ✅ **垂直职场** — 加班 / KPI / PUA / 35岁 / 摸鱼 |
| 视频生成 | 后期剪辑 | 模板生成 | ✅ Veo 3.1 / 即梦 实时 prompt-to-video |
| TTS | 普通 | 英文为主 | ✅ Minimax speech-2.8-hd 真人音色 23 种 |
| 真实文化锚 | 无 | 无 | ✅ 阿里黑话 / 班味 / 鼠人 / 真法条 |
| 用户共创 | 无 | 单人玩具 | ✅ "我贡献我的真实职场素材" → 平台分账 |

**护城河:** 我们已经有完整的"职场 prompt 工程 + 23 角色音色 + 阿里黑话词库",这些是独立做"AI 脱口秀"产品的人 0-1 都补不齐的。

## 3. 三阶段路线图

### Phase 1 · v0.7.0 — 脱口秀 MVP(4 周)

**目标:** 用户上首页能看到"🎤 班味单口"模式,点进去免登录看 1 段 AI 数字人讲职场段子,看完想点"我也想造一个"。

**功能切片:**
- [ ] **新模式入口** — Landing 加第 4 张大卡:"🎤 班味单口" (与经典 / 沉浸 / 裁了么并列)
- [ ] **首发"小鼠师傅"** — 我们预置的默认主播(Minimax `image-01` 出 1 个二次元说唱兔形象)
- [ ] **段子库** — `services/talkshowScripts.ts` 内置 30 段职场段子(纯文本 prompt → LLM 生成 → 人工筛 30 段固化为种子内容)
- [ ] **数字人渲染器** — 客户端 Canvas + 唇形帧动画(简化版:5 张嘴型张合,根据音频 amplitude 切)
- [ ] **TTS 实时流** — Minimax `speech-2.8-hd` 流式接口(已有同步接口,改流式只是 fetch chunked)
- [ ] **首页瀑布流** — `/talkshow` 列表页,每张卡 = 1 段已生成的视频缩略图

**技术栈:**
- 客户端:延用 React + Canvas
- 服务端:`packages/server/src/routes/talkshow.ts` + `services/talkshowGen.ts`
- LLM:Minimax M2 写段子(prompt 包含"段子结构:Setup → Punchline → Tag")
- TTS:Minimax `speech-2.8-hd` + 角色情感参数 `emotion: 'happy'/'angry'/'sarcastic'`
- 视频:**先不接 Veo**,客户端拿 audio + 静态头像 + 唇动帧拼成可下载的 mp4(复用 v0.4 的 ffmpeg 转码管道)

**工时:** 60-80h

**成功指标:**
- 1 周内 ≥ 50 段用户产出
- 单段最高分享 ≥ 1k(短视频平台)

### Phase 2 · v0.7.1 — 数字人定制(4 周)

**目标:** 用户能从 0 捏一个属于自己的"AI 脱口秀演员"。

**功能切片:**
- [ ] **角色编辑器** `/talkshow/create-character`
  - 性别 / 年龄段 / 风格(职场剧女主 / 中年油腻男 / 文艺青年 / 鼠系青年 / ...)
  - LLM prompt 自动转 Minimax `image-01` 提示词 → 生成 4 备选 → 选 1
  - 音色选择(23 种 Minimax voice 列表 + 试听)
  - 性格标签(社牛 / 阴阳怪气 / 暴躁 / 老油条 → 影响段子语气)
- [ ] **保存为"我的演员"** — localStorage + 后续接账号
- [ ] **段子主题输入** — 用户给 1 句话主题("被裁的第 7 天"),LLM 出完整 1 分钟段子 + 生成视频

**工时:** 60-80h

### Phase 3 · v0.7.2 — Veo 3.1 实景视频(6 周)

**目标:** 段子背景不再是静态房间,而是 Veo 3.1 生成的 5s 切片(玩家在工位 / 茶水间 / 老板办公室一边讲一边动)。

**功能切片:**
- [ ] **服务端 `/api/talkshow/render-video`** — Veo 3.1 API 集成(已有 VEO_API_KEY env)
- [ ] **场景 prompt 模板**:`"工位上,程序员 X 边敲键盘边吐槽:..."`
- [ ] **段子分段**:每 5-8s 一个场景,Veo 生 4-8 段 5s 视频,服务端 ffmpeg 拼接 + 叠 TTS 音轨
- [ ] **进度反馈**:Veo 单次出图约 30-60s,进度条显示"正在拍摄 第 3 / 6 个镜头"
- [ ] **缓存复用** — 同一 prompt 12h 内复用已生成视频片段

**工时:** 80-100h

**成本预算:**
- Veo 3.1 单次 5s 视频约 ¥1-3
- 一段 1 分钟段子 = 8 段 × ¥2 = ¥16
- toC 免费额度:每用户每月 3 段(¥48),超出引导付费 / Premium

## 5. 风险 + 对冲

| 风险 | 概率 | 对冲 |
|---|---|---|
| Veo 3.1 成本飘高 | 高 | 免费层限额 + 缓存复用 + 静态版兜底 |
| 段子触发审查 | 中 | 关键词审 + 用户协议禁政治宗教 + 人工二审热门 |
| 同质化(段子翻来覆去) | 中 | 题材池每周加 5 个新角度 + UGC 玩家提供素材 |
| 数字人形象侵权 | 低 | 训练 prompt 明确"原创二次元",不接受真人照片 |
| 桥桥子团队抄概念 | 中 | 我们的护城河是开源 + UGC + 职场垂直,他们追不上 |
